# Follow-along demo

## Prepare a tracked starting file

1. Open your cloned GitHub repository in VS Code. README.md should appear at its top level.
2. If the presenter asks you to follow along, copy ONLY receipt.py from this folder beside README.md. Its starting price is 2.50 and quantity is 2.
3. Keep existing work. If you already have the receipt file, check its content with the presenter instead of overwriting it.
4. Copy .gitignore beside README.md if there is none. If one exists, add __pycache__/ and *.pyc only if those entries are missing.
5. With help from the presenter if needed, stage the starter, commit Add receipt starter and push it. This gives later edits a recorded version to compare against.

## During the demonstrations

- The initial edit changes price from 2.50 to 3.00. Save, review, stage, commit and push when instructed.
- If you edited README.md during the demonstration, finish that edit too; do not leave unexpected pending changes before branch switching.
- At the later filename step, rename receipt.py to reciept.py in Explorer. Stage and commit the rename, then push. Keep only the renamed file.
- The branch illustration uses main at 2.50 and update-price at 3.00. Follow the presenter's explicit baseline preparation before reproducing it.
- Activity 1 is a separate task: it starts at 3.00 and ends at 3.50. Follow 02_ACTIVITY_1/INSTRUCTIONS.md for that task.
- The merge-conflict section is a presenter demonstration. Keep your own successful activity file intact unless told to follow along.

If you are only watching the demonstrations, you can start preparing your own receipt file directly using Activity 1's instructions when the presenter announces it.
